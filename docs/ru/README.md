TranslatedSubs — рабочая среда для обработки субтитров к видео и аудио. Она позволяет скачивать медиафайлы, распознавать речь, переводить субтитры и создавать отдельные файлы субтитров или видео со встроенными субтитрами. Задачами можно управлять через веб-интерфейс или MCP.

Сервис подойдёт людям и командам, которым нужно получить переведённые субтитры по ссылке на страницу видео или из локального файла. В одном месте можно следить за ходом задачи, исправлять текст и скачивать видео и файл SRT. Синхронизация с Google Drive необязательна. Элементы веб-интерфейса сейчас подписаны на китайском языке.

## Быстрый запуск с Docker

Выполните команды в корне репозитория:

```bash
cp .env.example .env
# Set SUBTRANS_DEEPSEEK_API_KEY in .env
docker build -t translatedsubs:local . && docker run -d --name translatedsubs --restart unless-stopped -p 8000:8000 --env-file .env -e SUBTRANS_DATA_DIR=/data -e SUBTRANS_DB=/data/db/app.db -v translatedsubs-data:/data translatedsubs:local
```

При обновлении существующего контейнера замените `translatedsubs-data` именем используемого тома, чтобы сохранить базу задач и созданные файлы. Переменные окружения `SUBTRANS_*` по-прежнему поддерживаются.

Откройте <http://localhost:8000/>. Проверьте доступность API командой `curl http://127.0.0.1:8000/api/health`: успешный ответ содержит `"ok":true`. Эндпоинт `/api/health/ready` также показывает состояние ключа перевода, FFmpeg, хранилища и фильтра для встроенных субтитров. Подробности локальной разработки и развёртывания см. в [указателе документации (на китайском языке)](../README.md).

## Возможности

- **Обработка субтитров**: Скачивание видео, извлечение аудио, распознавание и перевод речи, создание отдельных или встроенных в видео субтитров.
- **Веб-интерфейс**: Очередь задач, отслеживание выполнения, просмотр видео, редактирование субтитров и скачивание результатов в браузере.
- **Интеграция MCP**: Codex, Claude Desktop и другие ИИ-клиенты могут создавать задачи и отслеживать их с помощью естественного языка.
- **Расширение Google Drive**: Загрузка, скачивание и организация файлов по задачам для обмена результатами в команде.
- **Сменные средства распознавания**: Локальный faster-whisper, Replicate или совместимый HTTP-сервис на выбор с учётом стоимости, скорости и конфиденциальности.

## От видео к субтитрам

1. Вставьте ссылку на страницу видео в веб-интерфейсе или загрузите локальный файл. Сначала можно проверить ссылку с помощью теста загрузки.
2. Выберите исходный и целевой языки, только перевод или двуязычные субтитры, а также отдельные или встроенные субтитры. По умолчанию речь распознаёт локальный faster-whisper. Перед первой задачей скачайте выбранную модель в настройках локальных моделей и дождитесь статуса готовности.
3. Запустите задачу и следите в очереди за скачиванием, извлечением звука, распознаванием, переводом и созданием результата. После завершения можно просмотреть видео, исправить субтитры, повторно создать результат и скачать видео и SRT. Режим «только скачать» не создаёт субтитры.

Отдельные субтитры можно включать и выключать в проигрывателе. Встроенные субтитры записываются в изображение и требуют фильтра FFmpeg `subtitles` (libass). При первом запуске может понадобиться скачать модель и обратиться к внешним сервисам. ИИ-клиенты могут использовать тот же процесс по [руководству для MCP-агентов (на китайском языке)](../mcp-agent-guide.md).

## Основные настройки и данные

Скопируйте `.env.example` и укажите `SUBTRANS_DEEPSEEK_API_KEY` в `.env`. Все параметры и значения по умолчанию перечислены в [шаблоне переменных окружения](../../.env.example). Основные параметры:

| Параметр | Назначение |
| --- | --- |
| `SUBTRANS_DEEPSEEK_API_KEY` | Ключ DeepSeek для перевода субтитров; без него полный процесс не готов к работе. |
| `SUBTRANS_DATA_DIR`, `SUBTRANS_DB` | Пути к файлам и базе задач SQLite; в примере Docker они находятся в постоянном томе. |
| `SUBTRANS_TRANSCRIBER_BACKEND` | По умолчанию `local_whisper`; при необходимости выберите `replicate` или совместимый HTTP-сервис. |
| `SUBTRANS_COOKIES` | Файл cookie для сайтов, требующих входа или подтверждения возраста. |
| `SUBTRANS_WORKERS`, `SUBTRANS_DOWNLOAD_WORKERS` | Число параллельных задач обработки и скачивания. |

При обновлении контейнера используйте прежний том и сохраняйте базу SQLite вместе с результатами. Не добавляйте в репозиторий `.env`, cookie, данные OAuth и тестовые медиафайлы. Для Google Drive требуется отдельный sidecar; см. [локальный запуск (на китайском языке)](../local-quick-start.md).

## Частые проблемы

- API отвечает, но задачи не запускаются: проверьте `checks` и `capabilities` в `/api/health/ready`, включая ключ, FFmpeg/FFprobe, yt-dlp и хранилище.
- `MODEL_NOT_READY`: скачайте и проверьте выбранную модель Whisper в настройках локальных моделей.
- Встроенные субтитры недоступны: установите FFmpeg с libass или выберите отдельные субтитры. Проверка фильтра: `ffmpeg -hide_banner -filters | grep ' subtitles '`.
- Ссылка не скачивается: сначала запустите тест загрузки; если нужен вход на сайт, настройте `SUBTRANS_COOKIES` по [локальному руководству (на китайском языке)](../local-quick-start.md).

## Разработка

Проект использует Python 3.10–3.12, FastAPI, FFmpeg и обычный JavaScript. Для локальной разработки выполните `uv sync`, затем `uv run uvicorn src.handler.app:app --port 8000`; тот же сервер отдаёт веб-интерфейс. Запустите тесты Python командой `uv run pytest -q`, а тесты интерфейса — `npm test` из каталога `web/`. Проверки с реальными облачными сервисами включаются отдельно; см. [AGENTS.md (на китайском языке)](../../AGENTS.md).

`src/handler/` предоставляет HTTP API; `src/core/` выполняет скачивание, распознавание и обработку субтитров; `src/service/` и `src/store/` управляют задачами и данными; `src/mcp_server/` предоставляет MCP; в `web/` находится интерфейс. Правила разработки см. в [CONTRIBUTING.md (на китайском языке)](../../.github/CONTRIBUTING.md). О проблемах безопасности сообщайте конфиденциально согласно [SECURITY.md](../../.github/SECURITY.md), а не через публичную issue.
